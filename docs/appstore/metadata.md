## 宣传文本 (170 字以内)

把相机对准日语书，文中的语法点立刻高亮！点一下就能看到意思、用法、使用场景、词源和相近语法对比。完全离线，无需联网。

## 描述

读日语书时遇到看不懂的语法？打开「语法扫描」，对准书页即可。

【拍照即识别】
• 实时取景：相机画面中的语法点实时高亮，颜色按 JLPT 等级区分
• 定格精读：拍下当前页面，所有语法点在图片和文字中全部高亮
• 相册识别：从相册选择截图或照片同样可以识别
• 重叠的语法点会让你选择要看哪一个

【讲解详尽】
每个语法点都有：
• 意思：多义用法逐条说明
• 用法：接续方式、活用变化、注意事项
• 使用场景：书面/口语、什么场合用
• 词源：语法从哪里来，帮助真正理解
• 例句：日文 + 中文翻译，语法部分高亮
• 相近语法对比：讲清区别，一键跳转

【语法库与收藏】
• 内置 N5–N1 全部语法，可按等级浏览、搜索
• 收藏重点语法，随时复习

【隐私与离线】
• 文字识别在手机本地完成，不上传任何图片
• 不需要网络，不含广告与追踪

## App 隐私（App Store Connect → App 隐私）

- 开启 App 内反馈提交（CloudKit）之后：“是，我们从此 App 收集数据”，只勾选：
  - **用户内容 → 客户支持**（用户主动提交的反馈描述与截图）：用于 App 功能 / 客户支持；**不与用户身份关联**；**不用于追踪**
  - **诊断 → 其他诊断数据**（随反馈附带的 App 版本、系统版本、设备型号、界面语言）：同上
- 未开启 App 内反馈提交时：“否，我们不从此 App 中收集数据”

## 审核备注 (App Review Information → Notes)

本 App 完全离线运行，无需登录账号。
使用方法：在“扫描”页将相机对准任意印刷的日文文字（或点左下角“相册”选择含日文的图片），识别出的语法点会高亮显示，点击即可查看讲解。
相机权限仅用于在设备端识别文字。
