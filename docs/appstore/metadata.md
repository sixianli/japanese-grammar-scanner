## 描述

读日语书时遇到看不懂的语法？打开「日语语法速查」，对准书页即可。

【拍照即识别】
• 实时取景：相机画面中的语法点实时高亮，颜色按 JLPT 等级区分
• 定格精读：拍下当前页面，所有语法点在图片和文字中全部高亮
• 相册识别：从相册选择截图或照片同样可以识别
• 重叠的语法点会让你选择要看哪一个

【讲解详尽】
每个语法点都有：
• 意思：多义用法逐条说明
• 用法：接续方式、活用变化、注意事项
• 使用场景：书面/口语、什么场合用
• 词源：语法从哪里来，帮助真正理解
• 例句：日文 + 中文翻译，语法部分高亮
• 相近语法对比：讲清区别，一键跳转

【语法库与收藏】
• 内置 N5–N1 共 878 个语法点，可按等级浏览、搜索
• 收藏重点语法，随时翻看

【到时间就复习】
• 查过的语法按遗忘规律排好复习时间
• 首页提示「N 个语法可以复习了」，点一下看讲解、自评记住了没有

【隐私】
• 文字识别在手机本地完成，不上传任何图片；没网也能扫描和看讲解
• 不需要注册，不含广告与追踪
• 只收集匿名使用统计和你主动提交的反馈，不与身份关联

## App 隐私（App Store Connect → App 隐私）

开启 CloudKit（App 内反馈 + 匿名使用统计）之后：“是，我们从此 App 收集数据”，只勾选下面三项，每一项都选
**用于：App 功能 / 分析**（按下面说明）、**不与用户身份关联**、**不用于追踪**：

- **用户内容 → 客户支持**：用户主动提交的反馈描述与截图（用途：App 功能）
- **诊断 → 其他诊断数据**：随反馈附带的 App 版本、系统版本、设备型号、界面语言（用途：App 功能）
- **使用数据 → 产品交互**：匿名使用统计（打开次数与时段、查看的语法点与等级）（用途：分析）

国家 / 地区取自 App Store 店面，不是定位信息，不需要勾选「位置」。
未开启 CloudKit 时：“否，我们不从此 App 中收集数据”。

## 审核备注 (App Review Information → Notes)

本 App 全部功能免费，无内购，无需登录账号。扫描、讲解、复习都在设备上完成，不联网也能使用；联网时会通过 CloudKit 上传匿名使用统计和用户主动提交的反馈（不与身份关联）。
使用方法：在“扫描”页将相机对准任意印刷的日文文字（或点左下角“相册”选择含日文的图片），识别出的语法点会高亮显示，点击即可查看讲解。
相机权限仅用于在设备端识别文字。
