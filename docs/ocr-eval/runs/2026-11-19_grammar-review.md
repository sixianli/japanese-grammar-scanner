# 2026-11-19 语法误判修正（95 张照片逐块核对）

依据：3,601 个高亮块的人工核对（见 `2026-11-19_textband-nolc.md` 第 2 节）中的「语法不对」200 处、「存疑」69 处、「叠了多余的语法点」98 处、漏标 67 处。

## 改了什么

- **67 个语法点收紧规则**，每条误判句都加进该语法点的 `negativeExamples`（以后改规则时自动检查不会再犯）：
  - 词里碰巧含有语法的字：でたらめ / もしかしたら→たら，ちゃんと / きちんと / 割と→と，たっぷり→ぶり，くだけた→だけ，あしからず→しか，
    とりあえず / だけあって→合う，いつから→いつか，心より→より，なぜなら→なら，ふさふさ→さ，わくわくする→くする，間もなく→間，
    あさって→てまで，他のみんな→のみ，目に見える→に見える，ちょっと聞いて→と聞いた，まずして→ずして，
    いかが / さすが / ありがとう / ながら / ほうが→は〜が〜，のである→ので，それに次いで→それに，追いかける→かける 等；
  - 意思不对：〜たり〜たりして 不再标成句末「〜たりして」，でなくてはならない 不再标成「〜ではなくて」，誰でも / 何でも 不再标成
    「疑問詞＋も〜ない」，だろうと思う 不再标成「〜(よ)うと思う」，思うようにならない 不再标成「〜ようになる」，
    分かれる / 恵まれる 等自动词不再标成被动 等。
- **96 个语法点新增 `subsumes`**：大语法出现时，同一处的组成部分不再重复标出（〜と 被 と思う / からといって / によると 等隐藏；
  ではない / じゃない 被 わけではない / のではないか 隐藏；被动 被 ずにはいられない 隐藏……）。
  最严重的一处「〜んじゃないかと思っていました」从 7 个标签减到 3 个。
- **数据错误**：`you-da` 与 `you-na-example` 互相 subsumes，导致所有「ような / ように」两个都被隐藏（写真のような絵 等漏标的原因）。
  已修正，并在 `tools/validate_grammar.py` 加了互相 subsumes 的检查。
- **补漏**：〜ないところだった、不本意 / 末筆ながら、少しくらい 等。

## 评测（`tools/ocr_eval.py`，同一批 OCR 结果）

| | 修改前 | 修改后 |
|---|---|---|
| 语法召回率 | 89.9% | 89.4% |
| 语法精确率 | 96.8% | 96.7% |
| 标准答案里的语法点数 | 2,567 | 2,456 |
| 漏识别（绝对数） | 259 | 260～262 |

召回率下降几乎都来自「标准答案」变小：标准答案也是用同一套规则从人工录入的正文里算出来的，删掉约 110 个误判 / 重复标签后，
分母变小，而这些标签原本在识别结果里也都「找到了」。在修改前后都应识别的 2,428 个语法点上，召回率 89.50% → 89.29%（-0.21 个百分点），
多出的漏识别都是「真正的〜と被读错、原来靠 と思う 里重复的〜と 凑上」这类评测口径问题。
被核对出来的 119 句误判中 115 句已不再误判，剩下 4 句和以下几类是有意保留或需要别的办法：

- 可能动词（言える、書ける）标成「〜れる・〜られる」：这个语法点本身就包含「可能」用法，讲解页会定位到「可能」。
- 和该语法点自己的例句冲突、或很难与正确用法区分的（申し込み→〜込む、楽しみ→〜み、変なもの→〜ものだ 等）。
- 跨行、跨引号的匹配（需要在拼接文字时处理）、文字识别读错导致的误判。
