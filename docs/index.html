隐私政策

最后更新：2026-11-22
  • 一句话说明：本 App 不需要注册账号，不包含广告或任何第三方 SDK。文字识别全部在你的设备上完成。
  • 相机与照片：相机画面和你从相册选择的图片，只在你的设备上由 Apple Vision 识别文字，不会上传。拍照或从相册识别的图片保存在本机的「最近扫描」中，方便回看，可以随时删除。
  • 收藏、浏览与复习记录：收藏、浏览记录、复习记录（每个语法的记忆状态和下次复习时间）和设置只保存在本机，删除 App 即一并删除。
  • 匿名使用统计：为了解有多少人在用、来自哪些国家或地区、在什么时段使用、哪些语法点最常被查，App 每天会匿名上报一条使用汇总：日期、是否新安装、是否本周或本月第一次使用、当天打开次数、按小时的使用分布、查看过的语法点及其等级、App Store 所在的国家或地区、界面语言和 App 版本。不包含姓名、账号、设备编号或任何能识别你的信息，通过 Apple 的 iCloud（CloudKit）保存，只用于改进 App。可以随时在「设置 → 隐私」中关闭。
  • 反馈：只有当你在反馈页主动点击「发送」时，你选择的反馈类型、填写的描述、附上的截图、提交时所在的页面（例如正在看的语法），以及 App 版本、系统版本、设备型号和界面语言，才会通过 Apple 的 iCloud（CloudKit）发送给开发者。如果没能直接发送，你也可以改用邮件或其他方式发送。这些信息只用于排查问题和改进 App，不会提供给任何第三方。
  • 反馈（App 内提交未开启时）：在反馈页点「发送」后，会打开系统的邮件或分享面板，由你决定用哪个 App、发给谁；内容是你选择的反馈类型、填写的描述、附上的截图、所在的页面，以及 App 版本、系统版本、设备型号和界面语言。App 本身不会上传任何内容。
  • 联系我们：对本隐私政策有任何疑问，可以在「设置 → 反馈」中告诉我们。

支持

使用问题或建议，可在 App 内「设置 → 反馈」提交（可附截图），也可在本项目的 GitHub Issues 中反馈。
