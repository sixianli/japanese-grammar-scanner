# App 图标

`app-icon-1024.png`：和纸水墨风格。毛笔刷出的扫描取景框，右上角的框角换成一朵粉色樱花；中间竖排毛笔字「文法」（Yuji Syuku 字体，SIL OFL）。

- 扫描框：App 的核心功能（拍照识别）
- 樱花：日本元素
- 「文法」：日语的「语法」

深色版（`app-icon-dark-1024.png`）：墨色底、米白笔触和字、粉色樱花；着色版（`app-icon-tinted-1024.png`）：黑底白字的灰度图，系统按用户选的颜色着色。

App 内使用：`Assets.xcassets/AppIcon.appiconset`（主屏幕图标，含浅色 / 深色 / 着色三版）、`AppIconImage.imageset`（使用引导页）。
